## Case Study: Network Traffic and Latency Analysis

### The Problem

You’re monitoring a network where traffic (packets/second) and latency (milliseconds) vary with daily patterns, trends, and occasional spikes from user surges or attacks. Your goals are:

- Forecast traffic and latency for the next 24 hours to plan capacity.
- Analyze the series to detect anomalies (e.g., traffic spikes or latency surges).
- Estimate anomaly likelihood to set alerts.

We’ll use a synthetic hourly time series (168 hours, 7 days) with trends, daily seasonality, and nonlinear spikes, mimicking real network data.

---

## Step 1: Generating and Exploring the Data

Let’s simulate correlated network traffic and latency with trends, daily seasonality, and random spikes (inspired by jump-diffusion, Stochastic Part 4).

```python
import numpy as np
import matplotlib.pyplot as plt

# Set random seed
np.random.seed(45)

# Generate synthetic traffic and latency (168 hours = 7 days)
t = np.arange(168)
trend = 10 + 0.5 * t  # Linear trend
seasonality = 50 * np.sin(2 * np.pi * t / 24)  # Daily cycle
noise = np.random.normal(0, 10, 168)  # Gaussian noise
spikes = np.zeros(168)
spike_indices = np.random.choice(168, size=5, replace=False)  # 5 random spikes
spikes[spike_indices] = np.random.uniform(50, 100, 5)  # Spike magnitudes
traffic = trend + seasonality + noise + spikes
latency = 0.5 * traffic + np.random.normal(0, 5, 168)  # Correlated latency

# Plot
plt.figure(figsize=(12, 6))
plt.plot(t, traffic, label='Traffic (Packets/Second)')
plt.plot(t, latency, label='Latency (ms)')
plt.title('Synthetic Network Traffic and Latency')
plt.xlabel('Time (hours)')
plt.ylabel('Value')
plt.grid(True)
plt.legend()
plt.savefig('traffic_latency_series.png')
```

This creates traffic with a trend, daily peaks, and spikes, and latency correlated with traffic, resembling real network behavior.

## Step 2: Testing Stationarity (Part 1)

Models like SARIMA and VAR (Part 3) require stationarity (Part 1). Let’s test traffic with the Augmented Dickey-Fuller (ADF) test.

```python
from statsmodels.tsa.stattools import adfuller

# ADF test for traffic
result = adfuller(traffic)
print(f'Traffic ADF Statistic: {result[0]:.3f}')
print(f'p-value: {result[1]:.3f}')
print('Stationary' if result[1] < 0.05 else 'Non-Stationary')
```

The high p-value (>0.05) indicates non-stationarity due to trend and seasonality. SARIMA’s differencing will address this. Latency likely shows similar results.

## Step 3: Decomposing the Series (Part 1)

Let’s decompose traffic to confirm components.

```python
from statsmodels.tsa.seasonal import seasonal_decompose

# Decompose traffic (24-hour period)
decomp = seasonal_decompose(traffic, model='additive', period=24)
plt.figure(figsize=(12, 8))
decomp.plot()

```

The decomposition shows a trend, daily seasonality, and residuals with spikes, aligning with nonlinear dynamics (Part 4).

## Step 4: Univariate Forecasting with SARIMA (Part 3)

SARIMA (Part 3) models traffic’s trend and seasonality. We’ll fit a SARIMA(1,1,0)(1,1,0)24 model to forecast 24 hours.

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX

# Fit SARIMA for traffic
model = SARIMAX(traffic, order=(1, 1, 0), seasonal_order=(1, 1, 0, 24))
fit = model.fit(disp=False)
forecast = fit.forecast(steps=24)

# Plot
plt.figure(figsize=(12, 6))
plt.plot(t, traffic, label='Observed Traffic')
plt.plot(np.arange(168, 192), forecast, label='SARIMA Forecast', linestyle='--')
plt.title('SARIMA Forecast: Network Traffic')
plt.xlabel('Time (hours)')
plt.ylabel('Packets/Second')
plt.grid(True)
plt.legend()
plt.savefig('sarima_forecast.png')
print(f'SARIMA AIC: {fit.aic:.2f}')
```

The forecast captures trend and cycles. The AIC assesses fit quality.

## Step 5: Multivariate Forecasting with VAR (Part 3)

Traffic and latency are correlated, so let’s use VAR (Part 3) to forecast both jointly.

```python
import pandas as pd
from statsmodels.tsa.vector_ar.var_model import VAR

# Prepare data
data = pd.DataFrame({'Traffic': traffic, 'Latency': latency})
model_var = VAR(data.diff().dropna())  # Difference for stationarity
fit_var = model_var.fit(maxlags=1)
forecast_var = fit_var.forecast(data.diff().dropna().values[-1:], steps=24)

# Reconstruct levels
last_values = data.values[-1:]
forecast_levels = np.cumsum(forecast_var, axis=0) + last_values

# Plot
plt.figure(figsize=(12, 6))
plt.plot(t[-24:], traffic[-24:], label='Observed Traffic')
plt.plot(np.arange(168, 192), forecast_levels[:, 0], label='VAR Traffic Forecast', linestyle='--')
plt.plot(t[-24:], latency[-24:], label='Observed Latency')
plt.plot(np.arange(168, 192), forecast_levels[:, 1], label='VAR Latency Forecast', linestyle='--')
plt.title('VAR Forecast: Traffic and Latency')
plt.xlabel('Time (hours)')
plt.ylabel('Value')
plt.grid(True)
plt.legend()
plt.savefig('var_forecast.png')
```

VAR captures correlations, forecasting both series with interdependence.

## Step 6: Analyzing Nonlinear Dynamics (Part 4)

Nonlinear dynamics (Part 4) explain traffic spikes. Let’s reconstruct the phase space to visualize the attractor.

```python
from mpl_toolkits.mplot3d import Axes3D

# Phase space (m=3, tau=1)
tau = 1
m = 3
embedding = np.array([traffic[i:i+m*tau:tau] for i in range(len(traffic)-m*tau+1)])

# Plot
fig = plt.figure(figsize=(12, 6))
ax = fig.add_subplot(111, projection='3d')
ax.plot(embedding[:, 0], embedding[:, 1], embedding[:, 2], lw=0.5, color='blue')
ax.set_title('Phase Space: Network Traffic (m=3, τ=1)')
ax.set_xlabel('y(t)')
ax.set_ylabel('y(t-τ)')
ax.set_zlabel('y(t-2τ)')
plt.savefig('traffic_phase_space.png')
```

The complex attractor shows seasonality loops and spike distortions, confirming nonlinear behavior.

## Step 7: Detecting Anomalies (Inspired by Stochastic Part 5)

Spikes resemble jumps in jump-diffusion (Stochastic Part 4). Let’s detect anomalies using SARIMA residuals exceeding 2 standard deviations, inspired by HMMs (Stochastic Part 5).

```python
# Compute residuals
fitted_values = fit.fittedvalues
residuals = traffic - fitted_values
std_residuals = residuals.std()
anomalies = np.abs(residuals) > 2 * std_residuals
anomaly_indices = np.where(anomalies)[0]
anomaly_values = traffic[anomaly_indices]

# Plot
plt.figure(figsize=(12, 6))
plt.plot(t, traffic, label='Observed Traffic')
plt.scatter(anomaly_indices, anomaly_values, color='red', label='Anomalies', zorder=5)
plt.title('Network Traffic with Detected Anomalies')
plt.xlabel('Time (hours)')
plt.ylabel('Packets/Second')
plt.grid(True)
plt.legend()
plt.savefig('traffic_anomalies.png')
```

This flags spikes, useful for alerts.

## Step 8: Estimating Anomaly Probability with Monte Carlo (Stochastic Part 4)

Let’s estimate the probability of anomalies in the next 24 hours using Monte Carlo (Stochastic Part 4).

```python
# Monte Carlo simulation
n_sim = 1000
sim_residuals = np.random.normal(0, std_residuals, (n_sim, 24))
anomaly_prob = np.mean(np.abs(sim_residuals) > 2 * std_residuals)
print(f'Anomaly Probability (Next 24 Hours): {anomaly_prob:.3f}')
```

This quantifies anomaly likelihood, enhancing monitoring.

## Understanding Takens's Embedding
Takens's Embedding allow us to reconstruct the original time series with only a partial observed time series. We will see its effect on persistent homology.

### Simulation
Starting with a simple sine wave
![](/assets/images/understanding-takens/signal.png)

#### Experiment 1: Applying Takens's embedding to segments of the original data
We break the signal into segments, applying Takens's embedding on the segments, then concatenate them all

![](/assets/images/understanding-takens/takens.png)

We see that it closely resembles shape when applying to the whole dataset at once.

## Conclusion
We can say Takens's embedding is able to reconstruct the original time series with a certain confidence interval.

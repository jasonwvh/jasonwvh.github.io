## Introduction

Mapper is a topological data analysis algorithm that simplifies complex datasets by capturing their shape and structure. It creates a graph (simplicial complex) that highlights clusters, loops, and connections, making it easier to visualize and understand high-dimensional or noisy data. Mapper is especially useful for revealing patterns that traditional clustering or dimensionality reduction methods might miss.

## Simulating Data

Given two distinct circles in a point cloud
```python
import matplotlib.pyplot as plt
from sklearn import datasets

points, labels = datasets.make_circles(n_samples=2000, noise=0.1, factor=0.3, random_state=42)
fig = plt.figure(figsize=(5, 4))
ax = fig.add_subplot(111)
ax.scatter(points[labels == 0, 0], points[labels == 0, 1], c='blue', s=10, alpha=0.5, label='Label 0')
ax.scatter(points[labels == 1, 0], points[labels == 1, 1], c='green', s=10, alpha=0.5, label='Label 1')
plt.title("2D Circles")
plt.xlabel("x")
plt.ylabel("y")
plt.show()
```

## Visualizing Mapper

Before using Mapper, we will select the `l2norm` distance function to reduce our 2D data into 1D.

```python
import kmapper as km
from kmapper import Cover
from sklearn.cluster import KMeans

mapper = km.KeplerMapper()

lens = mapper.fit_transform(points, projection="l2norm")

G = mapper.map(
    lens,
    points,
    cover=Cover(n_cubes=15, perc_overlap=0.15),
    clusterer=KMeans(n_clusters=2, random_state=42)
)

_ = mapper.visualize(
    G,
    custom_tooltips=labels,
    color_values=labels,
    color_function_name="target",
    path_html="mapper.html",
    X=points,
    lens=lens,
)
```

Running the Mapper algorithm, we see two distinct, unconnected clusters.

## Adding dimensions
Mapper allows multiple lenses to give the graphs more information. 

For example, we can combine anomalies metrics from `IsolationForest` or  with distance metrics from `l2norm` or `PCA`

```python
from sklearn import ensemble

projector = ensemble.IsolationForest(random_state=42)
projector.fit(points)
lens1 = projector.decision_function(points)

mapper = km.KeplerMapper(verbose=1)
lens2 = mapper.fit_transform(points, projection="l2norm")

lens = np.c_[lens1, lens2]
G = mapper.map(
    lens,
    points,
    cover=Cover(n_cubes=15, perc_overlap=0.15),
    clusterer=KMeans(n_clusters=2, random_state=42)
)
```
